# ZH League

Season rankings and banter for a Generals Zero Hour crew. Nights → sets → points,
MVP/Noob votes, accusations, complaints, statuses, and a very honest newspaper.

**This repo is only the app code: no names, scores, keys or ID codes.**
League data lives in a separate private repo and is reached with a shared key
(delivered inside the group link). Each player then enters a personal ID code
generated in the app; codes are stored only as salted hashes, plus a copy
sealed for the super admin.

Scoring: win +3 · loss −1 · skipped a night with sets −0.5.
Original art and jokes; not affiliated with EA or the Command & Conquer series.
